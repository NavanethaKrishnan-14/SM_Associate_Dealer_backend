# Security Policy

## Supported versions

Security fixes are made against the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or a working proof of concept in a public issue. Use GitHub's **Report a vulnerability** option in this repository's Security tab to submit a private report. Include the affected repository/path, impact, reproduction steps, and any safe mitigation details.

Do not commit API keys, access tokens, database credentials, signing secrets, or production customer data. If a credential is exposed, revoke and rotate it immediately; removing it from a later commit does not make the exposed credential safe.
